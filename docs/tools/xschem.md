## 4. Stdio-only residue

4. STDIO-ONLY RESIDUE (and why): (i) C `info()/dbg()` diagnostics incl. netlist warnings + `exit 1` startup errors — C has no other sink than errfp (editprop.c:312-327); use `-l file`. (ii) ERC detail text — lives in `infowindow_text`, reachable on stderr or ONLY via `xschem netlist -messages` inside a script (scheduler.c:3786-3789); batch CLI prints just exit 10. (iii) Simulator child stdout/stderr — captured into Tcl vars `execute(data,$id)`/`execute(data,last)` via nonblocking pipe (xschem.tcl:242-352); headless `viewdata` is a no-op (`if {![info exists has_x]} {return}`, xschem.tcl:8416) so sim logs are SILENTLY DROPPED unless `--script` explicitly `puts $execute(data,last)` or reads `execute(exitcode,last)`. Why: xschem is a GUI-first Tcl/Tk app; batch mode reuses the GUI event loop, and result surfacing was built as dialogs. (iv) One-shot TCP replies (socket closed after each command) — must re-query per command.
